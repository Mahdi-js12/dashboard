# داشبورد مدیریتی پنل ادمین

یک داشبورد مدیریتی مدرن و حرفه‌ای با طراحی تیره (Dark Theme) و رنگ‌بندی مشکی و بنفش که برای مدیریت کسب‌وکارها، فروشگاه‌های آنلاین و سیستم‌های ادمین طراحی شده است.

![License](https://img.shields.io/badge/License-MIT-blue)

---

## ویژگی‌ها

- طراحی مدرن Dark Mode — ترکیب رنگی مشکی و بنفش با افکت‌های glow
- نمودارهای تعاملی — نمودار خطی فروش و نمودار دوناتی دسته‌بندی‌ها
- کاملاً ریسپانسیو — سازگار با موبایل، تبلت و دسکتاپ
- پشتیبانی از RTL — طراحی شده برای زبان فارسی
- بدون وابستگی به فریم‌ورک — استفاده از HTML، CSS و JavaScript خام
- انیمیشن‌های نرم — تجربه کاربری روان با transition‌های CSS
- جستجوی داخلی — باکس جستجو در نوار بالایی
- سیستم اعلان — نمایش نوتیفیکیشن‌ها با Badge
- جدول سفارش‌ها — مدیریت سفارش‌ها با وضعیت‌های مختلف
- تایم‌لاین فعالیت‌ها — نمایش رویدادهای اخیر سیستم

---

## تکنولوژی‌های استفاده شده

| تکنولوژی | کاربرد |
|----------|--------|
| HTML5 | ساختار صفحه |
| CSS3 | استایل‌دهی و انیمیشن‌ها |
| JavaScript (ES6+) | منطق تعاملی |
| Chart.js | رسم نمودارها |
| Vazirmatn Font | فونت فارسی |
